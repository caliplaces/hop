# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/caliplaces/hop/security/advisories/new),
not in public issues or pull requests.

We'll acknowledge your report, keep you updated while we fix it, and credit you
once it's resolved if you'd like.

Only the latest release (the `main` branch, running on onmyhop.com) receives
security fixes.
